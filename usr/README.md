# Poster Edukasi: Aman Digital untuk Anak Usia Dini

Aplikasi Flutter ini menampilkan antarmuka poster edukasi mengenai pentingnya keamanan digital (cybersecurity) untuk anak usia dini. Poster ini didesain secara proporsional sesuai rasio kertas A4 (21 x 29,7 cm) dan memuat:
- **Pertanyaan Pemantik** untuk mengajak orang tua merefleksikan keamanan gawai anak.
- **Fakta Didukung Referensi** yang relevan mengenai penggunaan gawai pada anak.
- **Materi Edukasi** yang berisi tips dan panduan praktis untuk orang tua.

Aplikasi ini responsif untuk dilihat melalui perangkat seluler maupun desktop.

## Cara Menjalankan
1. Pastikan Anda sudah menginstal Flutter.
2. Jalankan perintah `flutter pub get`.
3. Jalankan aplikasi menggunakan perintah `flutter run`.
